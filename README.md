# Toy Store Ecommerce Analysis
## Overview
#### This Project focuses on the exploration, analysis, modelling and visualization of data across multiple tables
#### Examples of explorations made include
- Calculating the Average Difference between the start of Website Session and Time Order was Placed
- Percentage of Orders that are below and Above Average Price
- Which Device People Place Order on Most
- Refund Rate of Product
- Calculating Number of Orders per Repeated Session
